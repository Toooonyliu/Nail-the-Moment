# Nail the Moment Presentation v11

11 页 HTML 演示，按用户提供的 Google Doc「讲稿」重新组织，使用「图像」页的场景素材。讲稿优先于较早的 Slide Story 文案，完整英文讲稿保留在 N 备注中。

1. 预约前的情景
2. 无需画图也能表达想法
3. 找回以前喜欢的美甲与生活瞬间
4. 产品介绍
5. 围绕一次预约收敛范围，展示实际早期探索
6. Moments 时间浏览与查找动图
7. 3D 探索动图
8. 单手持机与 AR 拇指控件，使用用户提供的真实手部 AR 录屏 GIF（移除浏览器边缘）
9. Rediscover、Explore、Preview、Share 连续演示
10. 可讨论的参考图与三个沟通线索
11. 以个人历史作为下一次创作的起点

方向键、滚轮或垂直滑动翻页。Home 回首页，N 打开完整讲稿，Escape 关闭。可用 `?slide=6` 直接打开某一页。

功能页使用本地 MP4 循环演示；第 8 页使用用户提供录屏转制的 GIF。视频支持 Pause/Play；GIF 使用 Stop/Replay，Replay 从头重播。仅当前页播放，页面隐藏时停止动画；系统减少动态效果时不自动播放。Try it live 切换到真正可操作的同源原型，Watch demo 返回录制。仅当前页、主动切换后的 iframe 运行。

场景图片用于讲述设想，不代表用户研究、真实测试或已验证结果。连续流程里的 AR 视频明确标示 camera-off 控件演示。第 8 页使用用户提供的真实手部 AR 录屏，Try it live 打开当前 AR 原型；第 6 页保持原样。完整照片到 3D 重建与社区发布仍为模拟能力。

媒体目录：`assets/photos/` 为原文配图的优化 JPEG；`assets/media/` 为实际原型录制与海报。原型切换使用固定 402×874 视口等比缩放。整个 presentation 目录应与 App 一起分享，保持原型入口可用。
